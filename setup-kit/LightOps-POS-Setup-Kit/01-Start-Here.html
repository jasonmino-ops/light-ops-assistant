店小二 POS 设备装机包 / LightOps POS Setup Kit

SV-04A Candidate

适用环境

Windows PC
Chrome 浏览器
Xprinter XP-N160II 80mm USB 打印机
USB 扫码枪
店小二 Desktop POS：elifekh.com
重要说明：本包是静态装机引导包，不会自动修改系统，不会自动安装驱动，不会自动修改 Chrome，不会绕过打印窗口。所有关键设置仍需装机人员人工确认。自动打印不是静默打印，销售完成后会自动弹出 Chrome 浏览器打印流程，店员仍需在 Chrome 打印对话框中按 Enter 或点击打印确认出纸。

装机步骤

  1. 确认 Windows 与网络。
  2. 确认或安装 Chrome。
  3. 安装 Xprinter XP-N160II 驱动。
  4. 设置 Xprinter 为默认打印机。
  5. 允许 elifekh.com 弹窗。
  6. 打印 Windows 测试页。
  7. 用最小真实销售触发店小二小票打印。
  8. 测试扫码枪连续扫码。
  9. 连续完成两单。
  10. 填写设备信息记录表。
  11. 给店员演示操作说明。
  12. 签字交付。
