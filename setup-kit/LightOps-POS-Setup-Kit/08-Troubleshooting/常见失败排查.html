店小二 POS 常见失败排查

关键规则：Windows 测试页失败时，不继续测试店小二小票。默认打印机必须是 Xprinter。第一单正常、第二单异常 = 装机验收不通过。打印后不回新订单若稳定复现，必须升级技术。

1. Chrome 不弹打印窗口

可能原因Chrome 拦截弹窗；销售未真正完成；打印窗口被其他窗口挡住。
检查步骤查看地址栏弹窗提示；检查是否有被最小化的打印窗口；确认订单已完成。
处理方式允许 elifekh.com 弹出式窗口和重定向；重新做一笔可作废最小真实销售测试。
是否升级允许弹窗后仍稳定不弹，升级技术排查。

2. Chrome 拦截 about:blank / 弹窗

可能原因Chrome 默认阻止新窗口或重定向。
检查步骤查看地址栏右侧是否有拦截图标；打开 Chrome 网站设置。
处理方式将 elifekh.com 设置为允许弹出式窗口和重定向。
是否升级设置后仍被拦截，升级技术排查浏览器策略。

3. 打印窗口弹出但不打印

可能原因未按 Enter 或点击打印；打印机选错；Xprinter 离线、缺纸或卡纸。
检查步骤确认打印对话框中打印机是 Xprinter；检查打印机灯号、纸卷和 USB 线。
处理方式选择 Xprinter，按 Enter 或点击打印；恢复打印机在线状态。
是否升级Windows 测试页也不能打印时，先处理 Windows / 驱动问题。

4. Windows 测试页能打，店小二小票不能打

可能原因Chrome 弹窗权限、打印窗口选择、页面打印预览异常。
检查步骤确认弹窗出现；确认打印机选择；记录测试销售订单号。
处理方式允许弹窗并选择默认 Xprinter，再做最小真实销售测试。
是否升级Windows 正常但店小二稳定失败，升级技术排查。

5. 小票能弹窗，但排版异常

可能原因纸张宽度、缩放比例、浏览器打印设置或驱动设置不正确。
检查步骤检查是否为 80mm 小票纸；查看打印预览缩放和边距。
处理方式选择正确纸张规格，使用默认缩放，避免手动改成不合适纸型。
是否升级设置正确仍异常，升级技术排查。

6. 默认打印机不是 Xprinter

可能原因Windows 自动切换默认打印机；安装了多台打印机。
检查步骤打开 Windows 打印机设置，查看默认打印机。
处理方式将 Xprinter XP-N160II 设置为默认打印机。
是否升级无法设置默认打印机时，升级现场 IT 或技术排查。

7. Xprinter 离线

可能原因USB 松动、打印机未开机、驱动异常、卡纸或缺纸。
检查步骤检查电源、USB、纸卷、Windows 打印队列。
处理方式重新插拔 USB，重启打印机，清理打印队列后再打印 Windows 测试页。
是否升级Windows 仍显示离线，升级驱动或硬件排查。

8. 扫码枪不能输入

可能原因USB 未连接、扫码枪未上电、焦点不在输入区域。
检查步骤插拔 USB；打开记事本扫码测试是否有数字输入。
处理方式恢复 USB 连接，将光标点回店小二输入区域。
是否升级记事本也无输入时，升级硬件排查。

9. 扫码枪能输入但系统不识别商品

可能原因商品条码未录入；条码输入多了前后缀；扫错商品码。
检查步骤核对屏幕输入的条码；换已知商品测试。
处理方式手动搜索商品继续营业，并通知老板补充商品条码。
是否升级大量已录入商品都不识别时，升级技术排查。

10. 自动打印没有触发

可能原因销售未完成；弹窗被拦截；浏览器窗口被遮挡。
检查步骤确认销售完成状态；查看 Chrome 弹窗权限；检查是否有打印窗口。
处理方式允许弹窗后重新做最小真实销售测试。自动打印只代表自动弹出打印流程，仍需店员在 Chrome 打印对话框确认一次。
是否升级稳定不触发，升级技术排查。

11. 打印后没有回到新订单

可能原因打印对话框未完成；浏览器未返回焦点；页面流程异常。
检查步骤确认已按 Enter 或点击打印；查看订单是否还停留在上一单。
处理方式完成打印确认后等待页面回到新订单。不要重复收银。
是否升级若稳定复现，必须升级技术排查。

12. 第一单正常，第二单异常

可能原因页面未正确清空订单；打印流程未闭环；浏览器状态残留。
检查步骤不刷新页面连续做第二单，记录第二单失败点和订单号。
处理方式停止装机验收，保留现场记录和设备信息。
是否升级第一单正常、第二单异常 = 装机验收不通过，必须升级技术。
