店小二 POS 店员操作说明

正常收银时，打印窗口出来后按 Enter 或点击打印，小票才会出来。小票没出来时，不要重复收银。已完成的销售不会因为刷新页面丢失。扫码失败时可以手动搜索商品继续营业。

每天开机怎么做

  1. 打开电脑，确认网络正常。
  2. 打开 Chrome。
  3. 进入 https://elifekh.com。
  4. 确认页面可以正常进入收银台。

怎么确认打印机正常

  • 确认打印机有纸、通电、USB 线接好。
  • 确认打印机没有显示离线或报错。
  • 如果刚开机，请等打印机启动完成后再收银。

怎么确认扫码枪正常

  • 扫码枪接到电脑后，扫商品条码应能听到正常提示音。
  • 如果扫不出来，可以先拔下 USB 再插回。
  • 如果商品没有识别，可以在店小二里手动搜索商品继续收银。

正常收银怎么做

  1. 扫码或搜索商品。
  2. 确认商品和金额。
  3. 完成收款。
  4. 看到 Chrome 打印窗口后，按 Enter 或点击打印。
  5. 小票出来后，页面应自动回到新订单。

小票没出来怎么办

  • 不要重复收银。
  • 先看有没有 Chrome 打印窗口被挡住或最小化。
  • 确认打印窗口里的打印机是 Xprinter。
  • 确认打印机有纸、在线、没有卡纸。
  • 如果仍然不出纸，请联系老板或技术人员。

扫码扫不出来怎么办

  • 确认扫码枪 USB 插好。
  • 换一个商品条码再试。
  • 可以手动搜索商品继续营业。
  • 如果很多商品都无法识别，请联系老板检查商品资料。

打印窗口被 Chrome 拦截怎么办

  • 看 Chrome 地址栏附近是否有弹窗拦截提示。
  • 选择允许 elifekh.com 的弹出式窗口和重定向。
  • 再进行一笔测试销售，确认打印窗口能出现。

收银完成后没有回到新订单怎么办

  • 先确认销售是否已经完成，不要重复收银。
  • 如果只是打印窗口还开着，请先完成打印确认。
  • 如果每次都不能回到新订单，请记录订单号并联系技术人员。
