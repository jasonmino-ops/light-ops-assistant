重要说明：

1. 真实驱动安装包不提交到 git。
2. 请将已验证的驱动安装包手动放入本文件夹。
3. 安装时必须确认型号为 XP-N160II。
4. 安装完成后必须设置为 Windows 默认打印机。
5. 必须先打印 Windows 测试页，再打印店小二小票。
6. 若 Windows 测试页失败，不得继续测试店小二小票。
7. 店小二自动打印不是静默打印，销售完成后会自动弹出 Chrome 浏览器打印流程，店员仍需在 Chrome 打印对话框中按 Enter 或点击打印确认出纸。
