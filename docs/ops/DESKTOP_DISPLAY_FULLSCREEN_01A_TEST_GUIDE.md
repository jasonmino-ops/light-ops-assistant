# Desktop-Display-Fullscreen-01A 测试指南

本指南用于验证电脑端顾客屏 `/desktop/display` 的手动进入/退出全屏能力。

## 范围

- 只验证顾客屏手动全屏入口。
- 不验证自动全屏。
- 不修改 PosSession 同步、KHQR 展示、收银完成逻辑。
- 不涉及数据库或 migration。

## 打开顾客屏

1. 在电脑浏览器打开：
   `/desktop/display?storeCode=ST169E7000&lang=zh`
2. 确认页面正常显示门店名、状态标签和语言切换。
3. 右上角应显示“进入全屏”按钮。

## 进入全屏

1. 点击“进入全屏”。
2. 浏览器应进入全屏模式，地址栏和浏览器顶部区域隐藏。
3. 右上角按钮文案应变为“退出全屏”。
4. 如果浏览器拒绝全屏，页面应继续可用；可使用浏览器或系统全屏快捷键。

## 退出全屏

1. 在全屏模式下点击“退出全屏”。
2. 浏览器应退出全屏模式。
3. 按钮文案应恢复为“进入全屏”。

## PosSession 同步回归

1. 在另一台电脑或另一个浏览器打开：
   `/cashier?storeCode=ST169E7000`
2. 在员工端添加商品。
3. 顾客屏应继续显示商品和金额。
4. 修改数量、删除商品、清空购物车，顾客屏应继续同步。

## KHQR 回归

1. 员工端选择 KHQR。
2. 顾客屏应继续显示本单金额和 KHQR 二维码。
3. 员工端切回 CASH 后，顾客屏应清除本单 KHQR。

## 空闲态回归

1. 清空购物车或完成销售。
2. 顾客屏应回到空闲态或完成态。
3. 空闲态欢迎页不应被全屏按钮遮挡。

## 常用退出方式

- Mac：`Control + Command + F`，或按 `Esc`。
- Windows Chrome / Edge：按 `F11`，或按 `Esc`。
- 浏览器 kiosk 模式：按系统或浏览器配置的退出组合键。

## 通过标准

- 顾客屏可手动进入全屏。
- 顾客屏可手动退出全屏。
- 商品 / 金额同步不受影响。
- KHQR 展示不受影响。
- 空闲态欢迎页不受影响。
- `/cashier` 员工端全屏能力不受影响。
