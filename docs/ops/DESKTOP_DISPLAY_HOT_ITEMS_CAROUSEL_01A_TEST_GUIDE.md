# Desktop-Display-HotItems-Carousel-01A 测试指南

本指南用于验证电脑端顾客屏 `/desktop/display` 空闲态“本周热销”图片自动轮播。

## 范围

- 只验证空闲态已有热销商品数据的前端轮播展示。
- 不改商品推荐算法。
- 不新增接口。
- 不改 PosSession 同步、KHQR 展示、全屏按钮或收银主链路。

## 打开顾客屏

1. 打开：
   `/desktop/display?storeCode=ST169E7000&lang=zh`
2. 确认当前没有进行中的订单。
3. 顾客屏应处于空闲态，并显示“本周热销”区域。

## 轮播验证

1. 确认“本周热销”区域每次只显示一张商品大图。
2. 确认商品名称正常显示。
3. 如有规格和价格，应正常显示。
4. 如果有多张热销商品图片，等待约 4 秒，确认切换到下一张。
5. 继续等待，确认到最后一张后会循环回第一张。
6. 如果只有一张商品图片，应稳定显示，不闪烁、不切换。

## 无图片兜底

1. 如果当前门店没有可展示图片商品，应显示原兜底空闲态。
2. 页面不应报错或白屏。

## 有订单时回归

1. 在另一浏览器打开：
   `/cashier?storeCode=ST169E7000`
2. 员工端添加商品。
3. 顾客屏应显示当前订单、商品和金额。
4. 此时不应显示热销轮播。

## KHQR 回归

1. 员工端选择 KHQR。
2. 顾客屏应显示 KHQR 二维码和本单金额。
3. 此时不应显示热销轮播。
4. 切回 CASH 后，顾客屏应清除本单 KHQR。

## 回到空闲态

1. 员工端清空购物车或完成销售。
2. 顾客屏应回到空闲态。
3. “本周热销”轮播应继续工作。

## 全屏按钮回归

1. 点击顾客屏右上角“进入全屏”。
2. 确认可以进入全屏。
3. 点击“退出全屏”后可退出。
4. 轮播展示不应遮挡或影响全屏按钮。

## 通过标准

- 空闲态每次只展示一张热销商品大图。
- 多图时约 4 秒自动切换并循环。
- 单图时稳定显示。
- 无图时兜底正常。
- 有订单、KHQR 支付态不显示热销轮播。
- PosSession 同步、KHQR 展示、全屏按钮不受影响。
