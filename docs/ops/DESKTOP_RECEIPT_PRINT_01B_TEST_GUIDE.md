# Desktop-ReceiptPrint-01B 80mm 小票模板与浏览器打印预览测试说明

## 范围

本轮只为电脑端 POS `/desktop/pos` 增加 80mm 小票预览与浏览器打印入口。

不做：

- 不接真实热敏打印机
- 不接 Electron / Tauri
- 不自动打印
- 不改 SaleRecord 结构
- 不改数据库
- 不改 Offline Sync
- 不改 `/sale`

## 测试前准备

1. 打开员工端：
   `/desktop/pos?storeCode=ST169E7000&lang=zh`
2. 打开顾客屏：
   `/desktop/display?storeCode=ST169E7000&lang=zh`
3. 确认商品、顾客屏、收银流程均正常。

## 路径 1：CASH 销售后预览小票

1. 在 `/desktop/pos` 选择商品。
2. 点击“确认本单”。
3. 点击“确认本单，选择收款方式”。
4. 选择 CASH。
5. 点击确认现金已收款并完成销售。
6. 销售成功弹层出现后，确认能看到：
   - 预览小票
   - 打印小票
7. 点击“预览小票”。
8. 确认小票包含：
   - 店名
   - 时间
   - 收银员
   - 商品
   - 数量
   - 单价
   - 金额
   - 支付方式
   - 订单号

## 路径 2：浏览器打印预览

1. 在销售成功弹层点击“打印小票”。
2. 浏览器打开打印预览或新打印窗口。
3. 确认小票宽度接近 80mm，实际内容宽度按约 72mm 排版。
4. 取消打印。
5. 确认 SaleRecord 已经创建，不受取消打印影响。

## 路径 3：中文 / 英文 / 柬文显示

1. 使用包含中文、英文、柬文名称的商品完成一笔销售。
2. 打开小票预览。
3. 确认商品名不乱码。
4. 确认长商品名可以换行。
5. 确认柬文行高足够，不叠字。

## 路径 4：KHQR 销售小票

1. 按电脑端 POS 标准流程完成一笔 KHQR 销售。
2. 打开小票预览。
3. 确认支付方式显示 KHQR。
4. 确认订单号、金额、商品明细正确。

## 路径 5：回归范围

1. 打开 `/cashier?storeCode=ST169E7000&lang=zh`。
2. 确认非 desktop `/cashier` 原成功弹层不受影响。
3. 打开 `/sale`。
4. 确认手机端商户收银页面不受影响。
5. 确认 `/records` 能看到销售记录。

## 验收结论

通过条件：

- `/desktop/pos` 完成 CASH / KHQR 销售后有小票预览/打印入口。
- 小票按 80mm 热敏纸方向设计。
- 取消浏览器打印不影响已完成销售。
- 不产生数据库 migration。
- `/cashier`、`/sale`、`/records` 主流程不受影响。
