# Desktop-Display-IdleLayout-01B 测试指南

本指南用于验证电脑端顾客屏 `/desktop/display` 空闲态布局收口：一屏稳定展示、热销图片为主、右侧 KHQR 位置稳定。

## 范围

- 只验证顾客屏空闲态布局。
- 不改 PosSession 同步。
- 不改 KHQR 生成、回调或查单。
- 不改 `/cashier` 收银主链路。
- 不涉及数据库或 migration。

## 打开顾客屏

1. 打开：
   `/desktop/display?storeCode=ST169E7000&lang=zh`
2. 使用常见电脑浏览器窗口，例如 1440x900 左右。
3. 确认页面非全屏状态下不再明显超出一屏。

## 空闲态布局

1. 确认左侧仍显示门店欢迎区和“本周热销”区域。
2. 确认热销轮播每次只显示一张商品。
3. 确认商品图片占主要视觉区域。
4. 确认商品名称和价格区域变轻，不抢占图片主体。
5. 等待多张轮播切换，确认布局高度稳定。

## KHQR 位置稳定

1. 观察右侧 Ready for checkout / Payment method / KHQR 区域。
2. 等待热销图片轮播切换。
3. 确认右侧 KHQR 区域不随左侧轮播上下跳动。
4. 确认空闲态常驻 KHQR 仍可正常展示。

## 有订单时回归

1. 在另一浏览器打开：
   `/cashier?storeCode=ST169E7000`
2. 员工端添加商品。
3. 顾客屏应显示当前订单、商品和金额。
4. 此时不显示热销轮播。

## KHQR 支付态回归

1. 员工端选择 KHQR。
2. 顾客屏应显示本单 KHQR 二维码和金额。
3. 切回 CASH 后，本单 KHQR 应清除。
4. 清空购物车或完成销售后，顾客屏回到空闲态轮播。

## 全屏按钮回归

1. 点击“进入全屏”。
2. 确认可进入全屏。
3. 点击“退出全屏”。
4. 确认可退出全屏。

## 通过标准

- 非全屏状态下页面不明显滚动。
- 热销轮播以图片为主。
- 商品名称/价格区域不抢占主要视觉。
- 右侧 KHQR 区域不随轮播跳动。
- 订单、KHQR、全屏按钮、PosSession 同步不受影响。
