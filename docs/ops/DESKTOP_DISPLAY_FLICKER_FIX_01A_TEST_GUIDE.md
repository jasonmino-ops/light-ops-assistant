# Desktop Display Flicker Fix 01A Test Guide

本说明用于验证 `/desktop/display` 顾客屏闪屏/抖动修复。此补丁只修渲染稳定性，不改 PosSession API、不改 KHQR 逻辑、不改 `/cashier` 收银主链路。

## 测试页面

- 员工端：`/cashier?storeCode=ST169E7000`
- 顾客屏：`/desktop/display?storeCode=ST169E7000`

建议使用两台电脑，或同一电脑的两个不同浏览器窗口。

## 基础加载

1. 打开顾客屏。
2. 确认首次加载后显示欢迎页、热销轮播或当前订单。
3. 等待 10 秒，确认后续轮询不会让整页反复回到 loading 或白屏。

## 加商品稳定性

1. 在员工端选择一个商品加入购物车。
2. 观察顾客屏在 0.5-1.5 秒内显示商品和金额。
3. 确认顾客屏没有明显整页闪白、抖动或重新加载。

## 修改数量稳定性

1. 在员工端修改同一商品数量。
2. 确认顾客屏金额和数量更新。
3. 确认商品行不整行闪白，商品图片不因数量变化重新加载。

## 支付方式切换

1. 在员工端切换到 KHQR。
2. 确认顾客屏显示 KHQR 区域和扫码提示。
3. 切回 CASH。
4. 确认顾客屏清除本单 KHQR，金额和商品区域稳定。

## 完成销售

1. 完成一笔测试销售。
2. 顾客屏应短暂显示完成态。
3. 约 2.5 秒后回到欢迎页或空闲态。
4. 确认旧商品、旧金额、旧 KHQR 不保留。

## 空闲态回归

1. 确认热销轮播仍正常自动切换。
2. 确认全屏按钮仍能进入/退出全屏。
3. 确认空闲态 KHQR 区域不随轮播跳动。

## 可选 DevTools 验证

在 Chrome DevTools 中打开 Rendering 面板，勾选 Paint flashing：

1. 加商品、改数量、切换 CASH/KHQR。
2. 观察页面重绘区域是否主要集中在商品、金额和支付区域。
3. 不应出现整页持续大面积闪烁。

## 回归边界

必须确认：

- 在线 CASH 收银不受影响。
- 在线 KHQR 收银不受影响。
- 离线 CASH 收银不受影响。
- PosSession 同步仍正常。
- 本补丁没有新增 API、migration、WebSocket/SSE 或动画库。
