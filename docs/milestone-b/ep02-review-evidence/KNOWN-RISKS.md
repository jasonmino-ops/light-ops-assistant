# EP-MB2-02 Known Risks

## Simulator Only

This package validates Device Runtime model behavior with simulator/runtime tests only.

No real Windows hardware is connected.

## No Executors

No printer, scanner, customer display, or cash drawer executor is implemented.

## No Scanner Router

Scanner source eligibility is validated, but no Scanner Router and no business/cart trigger is implemented.

## No Snapshot Store

Customer Display target eligibility is validated, but no Customer Display Snapshot Store is implemented.

## Pending External Gates

Windows CI and Vercel Preview must pass before Architecture Review can proceed to any Acceptance discussion.
