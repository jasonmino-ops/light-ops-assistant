桌面入口整理（首次安装或升级）

日常只推荐「店小二收银」。设置、原 Desktop 绑定和卸载收纳到开始菜单「店小二 → 管理与维护」。

旧安装器没有记录快捷方式的创建来源。请仅确认由安装器创建的默认入口；自建、修改过、同名冲突或无法确认的文件不会被覆盖。原 Desktop 程序与身份不变。

只处理当前用户桌面的已确认入口。全机桌面图标、重定向目录或跨磁盘迁移不能安全完成时会保留并提示。备份保存在 Network 专属 shortcuts 目录，不在打印 journal 中。正常卸载仅恢复仍可验证且原位置空闲的 Desktop 入口。

1 选择打印方式

已配置模式在此锁定；变更模式请使用下方冷切换。每店只能运行一个 Network Agent；不能同时使用旧打印方式打印同一订单。

2 选择并确认打印机

只检查当前直连有线 / Wi-Fi 私网的常用 RAW 端口。发现过程不出票；开放端口不代表可以打印。大网段、非默认端口请手工填写。

地址只保存在本机加密配置中，不会上传。仅支持当前物理局域网内的 RFC1918 IPv4 地址。

3 开始营业

首次设置请按需要勾选登录自启；启用打印不会擅自恢复已关闭的自启。以后点击桌面「店小二收银」即可准备本地服务并开页；普通未启用 Network 的收银入口不创建网络任务。

变更已配置模式（冷切换）

仅支持同一门店、同一台已确认打印机在「仅前台票」与「一机两张票」间变更。此操作不发送 TEST，也不出票。

先关闭本店所有电脑的 Network 收银标签页并停止新单，再点击「暂停并安全退出」。重新打开本程序，保持暂停，确认以下事项后变更。切换成功会再次退出；重启后需手动启用，并使用新的收银入口。

程序会检查本地记录与云端队列。存在待处理、未确认或结果不明的任务时会拒绝切换，请核对原订单并联系负责人；不要清空记录、重装、重打或重提销售。暂停不等于云端队列已清空。

打印异常、残缺票或停用时怎么办？

先核对原订单和实际纸票，再暂停处理。TCP 提交成功不等于纸张打印完成。

结果不确定时不会自动重打。不要删除 journal、重装以清空记录，也不要重新提交销售来补票。保留下面的任务号和错误代码，交由负责人核对原订单；厨房残缺票需人工确认菜品并记录处理。

停用 Network 时，关闭所有 Network 收银标签页并移除相应书签，再选择既有工作方式。停用不取消历史任务。

地址改变：暂停 → 重新发现或填新地址 → 主动 TEST → 确认仍为原打印机 → 保存并启用。不能确认同一设备时保持暂停。
